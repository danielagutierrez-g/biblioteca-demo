# Biblioteca personal

Demo estática para registrar, buscar y quitar libros. Está relacionada con el tema de gestión de libros del repositorio [`libreriaEstructura`](https://github.com/danielagutierrez-g/libreriaEstructura); esta interfaz no se conecta a ese proyecto Java.

## Uso

Abre `index.html` en un navegador. Los registros se guardan en `localStorage` de ese navegador.

La aplicación usa HTML, CSS y JavaScript sin dependencias. GitHub Actions publica los archivos en Pages al actualizar `main`.
